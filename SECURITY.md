# Security

## Reporting a vulnerability

Report security issues privately through GitHub's [private vulnerability reporting](https://github.com/backsight-app/backsight/security/advisories/new) (Security tab, **Report a vulnerability**), not in a public issue. Include what you found and how to reproduce it.

Reports are acknowledged as soon as possible and you will be told when a fix ships. Backsight is a small free project and has no bug bounty.

## Supported versions

Only the latest release is supported. Installed copies update themselves; updates are signed with minisign and verified before they install ([ADR 0014](docs/adr/0014-updates-from-github-releases.md)).

## Non-security issues

Use a normal [issue](https://github.com/backsight-app/backsight/issues). Problem reports list the programs that were running; review them before posting (see the [privacy statement](docs/privacy.md)).
