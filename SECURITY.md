# Security

## Reporting a vulnerability

Please report security problems privately, not in a public issue.

1. Go to the [Security tab](https://github.com/backsight-app/backsight/security) of the repository.
2. Choose **Report a vulnerability** (GitHub's private vulnerability reporting).
3. Say what you found and how to repeat it.

We'll reply as soon as we can and tell you when it's fixed. Backsight is a small free project, so there's no bounty.

Only the latest release is supported.

For problems that aren't security-related, open a normal issue. Don't paste problem reports into public issues without reading them first: they list the programs that were running. See the [privacy statement](docs/privacy.md).
