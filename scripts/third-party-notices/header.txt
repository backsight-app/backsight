========================================================================
1. FFmpeg and the libraries it is built with
========================================================================

Backsight uses FFmpeg (https://ffmpeg.org) as separate DLL files in this folder. FFmpeg and the
libraries it is built with have their own license files here, named LICENSE-*.txt
(for example LICENSE-ffmpeg-COPYING-GPLv3.txt and LICENSE-x264-COPYING.txt).
FFMPEG-BUILDINFO.txt says exactly how this FFmpeg was built, and FFMPEG-SOURCE.txt says where
to get its complete source code.
